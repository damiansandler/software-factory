# Runbooks

Step-by-step guides for when something goes wrong, one file per symptom. Write one when a
failure was hard to diagnose or is likely to come back (`/debug` adds them).

Each runbook: the symptom as the user or the logs show it, how to confirm the cause, the steps
to fix it, and how to check it's fixed.
