# Providers

One file per external provider or service the app depends on (`<provider>.md`). Read the
provider's file before touching its integration, and update it when you learn how it really
behaves.

Each file: what we use it for, environments and base URLs, how we authenticate (variable
names, never values), the calls we make and what each one returned when verified (with the
date), limits, known quirks, and open questions.
