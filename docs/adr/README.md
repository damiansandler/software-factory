# Architecture Decision Records

Durable product and architecture decisions, one per file, in the
[MADR](https://adr.github.io/madr/) style ([template](template.md)). An ADR is never deleted:
when a decision changes, a new ADR supersedes it. Minor decisions taken during a build live in
`specs/NNN-name/decisions.md`.

File name: `NNNN-short-title.md` (four digits, next free number).
